          DETERMINISTIC DEFENSE-IN-DEPTH
          
    
            
            The Four Pillars of KAVACH Cyber-Armor
          
    
          
    
            A layered security architecture ensuring that if one boundary is probed, the next layer mathematically neutralizes the exploit.
          
    
        
    
      
    

      
    
        
        
        
    
          
    
            
    TIER 1
    
            
    
              
    Adversarial AI & Canonical Token Shield
    
              Prompt Layer • Zero-Token Leakage
            
    
          
    
          
    
            Elite hackers use multi-layer Base64, Hex encoding, and Unicode homoglyphs to slip past naive regex. KAVACH deploys a canonical decoding pipeline before any semantic evaluation occurs.
          
    
          
      
            
    • Canonical Normalization: Unwraps Base64, Hex, URL encoding, and Unicode direction overrides (\u202E) into raw canonical ASCII.
      • 
            
    • Cryptographic Nonce Boundaries: Encloses untrusted user code inside per-session cryptographic XML tags (e.g. <untrusted_nonce_7f2a>) preventing prompt jailbreak escape.
      • 
            
    • Dual-Model Guardrail: An isolated, fine-tuned lightweight classifier (DeBERTa-v3 / Llama-Guard) evaluates prompt risk independently of the code synthesizer.
      • 
          
    
          
    
             0 Tokens dispatched to LLM on adversarial detection
          
    
        
    

        
        
    
          
    
            
    TIER 2
    
            
    
              
    AST Supply Chain & Slopsquatting Firewall
    
              Dependency Layer • Registry Attestation
            
    
          
    
          
    
            Hackers monitor LLM hallucinations and register backdoored packages on PyPI (AI Dependency Confusion). KAVACH intercepts imports via AST before any code can run or install.
          
    
          
      
            
    • Static AST Import Extractor: Parses Python Abstract Syntax Trees using ast.parse to identify every external module import.
      • 
            
    • Live PyPI Registry API Verification: Real-time lookup against official PyPI JSON endpoints; non-existent packages are halted immediately.
      • 
            
    • Package Age & Velocity Gate: Any package registered <30 days ago or with zero download history is automatically quarantined for manual review.
      • 
          
    
          
    
             100.0% Hallucinated Package Interception (50/50 caught)
          
    
        
    

        
        
    
          
    
            
    TIER 3
    
            
    
              
    Zero-Trust Ephemeral MicroVM & eBPF Probe
    
              Execution Layer • RCE Containment
            
    
          
    
          
    
            When KAVACH executes tests (ReAct self-healing loop), code is NEVER executed on the host OS or a standard Docker daemon where container breakouts are possible.
          
    
          
      
            
    • gVisor / Firecracker MicroVM: Dedicated user-space kernel virtualization with independent syscall tables. Memory is 100% ephemeral in RAM.
      • 
            
    • Strict Zero-Egress Network Isolation: Code executes with --network none. Sockets cannot establish outbound connections; reverse shells drop with ENETUNREACH.
      • 
            
    • eBPF Kernel Interception: In-kernel BPF probes monitor sys_enter_connect, sys_enter_execve, and kill rogue processes in <1.5 milliseconds.
      • 
          
    
          
    
             0.00 KB Network Egress • Complete Ram Wipe in 200ms

          ACADEMIC VIVA & EVALUATION GUIDE
          
    
            
            Viva Defense: How to Answer Ma'am's Toughest Cross-Questions
          
    
          
    
            Exact, rock-solid technical answers prepared for the Project-IV evaluation committee and Prof. Anusha Chhabra.
          
    
        
    
      
    

      
    

        
    
          
            Q1: "What if a top-tier hacker uses an unknown zero-day exploit that is not in your regex patterns?"
            ↓
          
          
    
            
    
              The Defense: "Ma'am, regex is only our Tier-1 pre-filter for sub-5ms low-hanging fruit. Even if a top hacker bypasses regex with a novel zero-day payload, they hit our Tier-3 Ephemeral MicroVM Sandbox (gVisor)."
            
    
            
    
              The execution sandbox is booted with --network none (zero outbound network egress). Even if the hacker's payload successfully executes os.system('/bin/bash'), the kernel network namespace has no external route. The reverse shell cannot phone home, no DNS packets can escape, and Linux eBPF probes intercept unauthorized syscalls in under 1.2ms. The entire microVM is wiped clean from RAM immediately after testing.
            
    
          
    
        
    

        
    
          
            Q2: "What if the hacker encodes the prompt in Base64 or exotic Unicode to bypass your prompt filters?"
            ↓
          
          
    
            
    
              The Defense: "We implement Canonical Token Normalization as step zero of the pipeline."
            
    
            
    
              Before any policy evaluation or LLM tokenization takes place, KAVACH recursively decodes Base64, Hexadecimal strings, URL encoding, and reverses Unicode bidirectional overrides (such as \u202E). The obfuscated payload is flattened into plain ASCII text, exposing the underlying malicious intent to our Shannon entropy scanner and AST parsers.
            
    
          
    
        
    

        
    
          
            Q3: "Can an attacker steal AWS keys, DB passwords, or PII from the agent's memory?"
            ↓
          
          
    
            
    
              The Defense: "No, because production secrets never enter the LLM's context window."
            
    
            
    
              KAVACH enforces a Zero-Knowledge Token Vault. All Aadhaar numbers, PAN cards, AWS keys, and credentials are stripped and substituted with synthetic pseudonyms (e.g., KAVACH_TOKEN_7F3A) prior to cloud dispatch. Furthermore, we deploy active Honeytoken Canaries—if any malicious prompt attempts to dump memory or environment variables, touching a decoy canary key triggers an immediate hard pipeline abort and alerts the SOC.
            
    
          
    
        
    

        
    
          
            Q4: "How does KAVACH stop AI dependency attacks like slopsquatting?"
            ↓
          
          
    
            
    
              The Defense: "Through our deterministic AST Package Firewall."
            
    
            
    
              LLMs frequently hallucinate package names that attackers subsequently register on PyPI with backdoors. When KAVACH synthesizes code, an AST visitor extracts all import statements and verifies them against the official PyPI JSON REST API. Packages that do not exist or packages registered <30 days ago with zero download velocity are quarantined before any pip install command can execute. In empirical tests, this achieved a 100.0% catch rate across 50 hallucinated packages.
