Two Mathematical Pillars Behind the Platform

  • 01

    Deterministic Multi-Layer Security Engine (1.00 F1 Score)

    Unlike probabilistic LLM guardrails that hallucinate safety, KAVACH executes deterministic token pattern analysis and checksum validation across Aadhaar formats (Verhoeff algorithm validation), PAN structures (5 letters, 4 digits, 1 letter), phone numbers, and enterprise API keys. Evaluated against a 42-run rigorous test dataset with zero false positives or false negatives.

  • 02

    AST-Driven Blast-Radius & Dependency Analysis (0.72 Avg F1)

    Parses the entire target repository into Python Abstract Syntax Trees (AST) to generate an acyclic dependency graph. When an AI proposes a code modification, KAVACH traverses inbound and outbound import edges to calculate the exact blast radius — notifying developers of downstream breakage risk before committing to main.

Honest Limitations & Architecture Roadmap

What KAVACH Does and Does Not Do Yet

Current Operational Reality

Dynamic Python runtime attributes (such as getattr or dynamically imported modules) are not fully captured by static AST parsers alone. Dynamic call trace analysis was designated for Phase 2.

Language Coverage Boundary

The AST engine currently specializes in Python repositories. Cross-language dependency analysis for polyglot microservices (Go/Rust/TypeScript) is under active development.

Air-Gapped LLM Roadmap

The system currently integrates Google Gemini API with fallback to local Ollama models (Llama 3 / DeepSeek Coder) for sovereign air-gapped defense environments.
